ข้อกำหนดการใช้งาน

อัปเดตล่าสุด: 12 พฤศจิกายน 2026

การเข้าชมและใช้งานเว็บไซต์ NES Blockchain ถือว่าผู้ใช้ยอมรับข้อกำหนดนี้ หากไม่ยอมรับ กรุณาหยุดใช้งานบริการ

การใช้งานที่อนุญาต

ผู้ใช้ต้องใช้งานบริการตามกฎหมาย ไม่รบกวนระบบ ไม่พยายามเข้าถึงข้อมูลหรือบัญชีของผู้อื่น และต้องรักษาความปลอดภัยของบัญชีและ credential ของตนเอง

บัญชีและการเข้าสู่ระบบ

การเข้าสู่ระบบผ่าน Google, GitHub หรือ Microsoft อยู่ภายใต้เงื่อนไขของผู้ให้บริการนั้น ผู้ใช้ต้องให้ข้อมูลที่ถูกต้องและรับผิดชอบต่อการใช้งานบัญชีของตน

เครื่องมือและบริการภายนอก

หน้าเว็บอาจเชื่อมโยงไปยัง MCP, Secrets Server, IPFS, OneDrive หรือบริการอื่นของบุคคลที่สาม เราไม่ได้รับประกันความพร้อมใช้งาน ความถูกต้อง หรือเงื่อนไขของบริการภายนอกเหล่านั้น

ความปลอดภัย

ห้ามนำ private key, OAuth Client Secret, access token หรือข้อมูลลับใด ๆ มาเผยแพร่บนเว็บไซต์หรือ repository สาธารณะ หากพบการเปิดเผยข้อมูลลับ ให้หยุดใช้งานและหมุน credential ทันที

สถานะบริการ

บางส่วนของ NES Blockchain เป็นโครงการทดลองหรือเครื่องมือแบบ static จึงอาจมีการเปลี่ยนแปลง หยุดให้บริการ หรือจำกัดการเข้าถึงได้โดยไม่ต้องแจ้งล่วงหน้า

การจำกัดความรับผิด

บริการจัดให้ตามสภาพที่มี เราจะพยายามดูแลระบบอย่างเหมาะสม แต่ไม่รับประกันว่าจะไม่มีข้อผิดพลาดหรือการหยุดชะงักทั้งหมด ผู้ใช้ควรสำรองข้อมูลและตรวจสอบผลลัพธ์ก่อนนำไปใช้จริง

การเปลี่ยนแปลงข้อกำหนด

เราอาจปรับปรุงข้อกำหนดนี้ เมื่อมีการเปลี่ยนแปลงจะปรับวันที่อัปเดตบนหน้านี้
