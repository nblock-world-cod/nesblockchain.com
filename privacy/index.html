นโยบายความเป็นส่วนตัว

อัปเดตล่าสุด: 12 พฤศจิกายน 2026

NES Blockchain ให้ความสำคัญกับความเป็นส่วนตัวของผู้ใช้ นโยบายนี้อธิบายข้อมูลที่อาจได้รับเมื่อผู้ใช้เข้าใช้งานเว็บไซต์หรือระบบที่เกี่ยวข้อง

ข้อมูลที่อาจได้รับ

เมื่อผู้ใช้เข้าสู่ระบบผ่านผู้ให้บริการภายนอก เช่น Google, GitHub หรือ Microsoft ระบบอาจได้รับข้อมูลพื้นฐานตามที่ผู้ใช้อนุญาต เช่น ชื่อที่แสดง อีเมล และรหัสระบุบัญชีจากผู้ให้บริการนั้น

การใช้ข้อมูล

  • ยืนยันตัวตนและจัดการ session ของผู้ใช้
  • ให้สิทธิ์เข้าถึงบริการที่ผู้ใช้ได้รับอนุญาต
  • ดูแลความปลอดภัย ป้องกันการใช้งานที่ผิดปกติ และแก้ไขปัญหา
  • ติดต่อผู้ใช้เมื่อจำเป็นเกี่ยวกับบริการ

ข้อมูลที่เราไม่ควรได้รับ

เว็บไซต์จะไม่ขอรหัสผ่านของ Google, GitHub หรือ Microsoft และไม่ควรได้รับ OAuth Client Secret, private key หรือ token ลับของผู้ใช้ผ่านหน้าเว็บ

การแบ่งปันข้อมูล

เราไม่ขายข้อมูลส่วนบุคคล ข้อมูลอาจถูกส่งต่อให้ผู้ให้บริการโฮสติ้ง ระบบยืนยันตัวตน หรือบริการที่ผู้ใช้เลือกเชื่อมต่อเท่าที่จำเป็นต่อการทำงานและความปลอดภัย

บริการภายนอก

ลิงก์ไปยัง Google, GitHub, Microsoft, IPFS, OneDrive หรือบริการอื่นอยู่ภายใต้นโยบายความเป็นส่วนตัวของผู้ให้บริการเหล่านั้น

การเก็บรักษาและการลบข้อมูล

เราจะเก็บข้อมูลเท่าที่จำเป็นต่อการให้บริการและความปลอดภัย ผู้ใช้สามารถติดต่อเพื่อสอบถาม แก้ไข หรือลบข้อมูลที่เกี่ยวข้องได้ โดยอาจต้องยืนยันตัวตนก่อนดำเนินการ
