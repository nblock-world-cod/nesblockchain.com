เริ่มต้นจากเครื่องมือที่ใช้งานได้ในเบราว์เซอร์และโครงการโอเพนซอร์สที่ตรวจสอบได้

UTILITY

SHA-256 Generator

สร้างรหัสเรียงลำดับและคำนวณ SHA-256 ด้วย Web Crypto API บนอุปกรณ์ของคุณ พร้อมดาวน์โหลดผลลัพธ์เป็น CSV หรือ JSON

LOCAL WINDOWS TOOL

Windows SSH Key Generator

สคริปต์ Windows สำหรับสร้าง Ed25519 key และบันทึกในโฟลเดอร์ .ssh โดยไม่ส่ง private key ออกจากเครื่อง

Model Context Protocol

Repository-first

ซอร์สโค้ดและเอกสารเผยแพร่ผ่าน GitHub เพื่อให้ตรวจสอบการเปลี่ยนแปลงและนำไปศึกษาต่อได้

หลักการทำงาน

ความปลอดภัยมาก่อน: เครื่องมือบนเว็บไซต์จะไม่สามารถเขียนไฟล์ .ssh ของ Windows โดยตรง การสร้าง SSH key ต้องรันสคริปต์ในเครื่องของผู้ใช้เอง และ private key ไม่ควรถูกอัปโหลดไปยัง GitHub หรือบริการใด ๆ
